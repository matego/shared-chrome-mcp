# Security

Report a vulnerability privately through GitHub: **Security** > **Report a vulnerability** in this repository (https://github.com/zucchini-chat/shared-chrome-mcp/security/advisories/new). Please don't open a public issue for it.

Ordinary bugs go to [issues](https://github.com/zucchini-chat/shared-chrome-mcp/issues).

By design, the CDP port gives every process on the machine the whole logged-in profile (README > Security); that alone is not a vulnerability.
